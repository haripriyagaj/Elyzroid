# 🛡️ Elyzroid
### A Privacy-Preserving Hybrid On-Device Framework for Android Malware Detection with Explainable AI

---

## 📖 Overview

Elyzroid is an AI-powered Android malware detection framework that performs malware analysis directly on the user's device while preserving privacy.

The system detects malicious APKs, fake banking notifications, phishing messages, suspicious permissions, and risky application behaviour without sending sensitive information to cloud servers.

Explainable AI provides users with understandable reasons for every detection decision.

---

## 🎯 Objectives

- Detect Android malware in real time.
- Perform on-device malware analysis.
- Preserve user privacy.
- Detect phishing notifications.
- Explain AI predictions.
- Alert users and optionally remove malicious files.
